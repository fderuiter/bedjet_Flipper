# Security and device behavior

This is an experimental local remote, not a security product. A BLE write being
accepted does not prove a setting was applied. The initial version has not been
tested with a physical BedJet or Flipper.

Use GitHub issues for ordinary bugs with sanitized reproductions. For an issue
that would disclose credentials, private data or a sensitive vulnerability,
use GitHub private vulnerability reporting if enabled. If unavailable, contact
the repository owner through their published GitHub profile contact channel
before posting sensitive details publicly. No private-reporting channel or
response SLA is currently guaranteed.

Do not include Wi-Fi passwords, access tokens, Bluetooth pairing keys, complete
personal packet captures or unnecessary identifying device information in issues.
Keep test captures limited to the fields needed to reproduce the behavior.

Do not bypass BedJet firmware limits or disable its protection mechanisms.
Protocol compatibility problems should be investigated with captures, bounds
checks and controlled device tests.
